## Top 3, and why they rank above the rest

1. **Institutional ownership (13F).** The only item on this list that is a different ACTOR
   (institutional capital flow) rather than a different cut of price, earnings, or revision data —
   which is precisely what the arena's own diagnosis says is missing (`docs/ROADMAP_2026-08-24_CONNECT_THE_BRAIN.md`:
   "all ten arena books declare `selection: composite_top_k` over ONE signal... a new mechanism
   arrives as its own book, never as a weight"). Data is entitled via WRDS per CLAUDE.md's own
   repository table; the main open question is whether the specific 13F table is pulled yet, which
   is one `data_catalog --query` away from an answer.
2. **Volatility (variance risk premium).** The `vol_compression` hyp_lab family already exists —
   infrastructure cost is sunk — and `features_options.parquet` already carries 1998-2024 of
   options-derived features, so this is a survey-then-build task, not a data-acquisition task.
   Distinct mechanism family (risk premium, not return-predictive drift) from everything else
   already running.
3. **Regime changes.** The newest, least-tested piece of infrastructure in the whole repository
   (`world_state`/`regime_v1`, built the same day as this queue), which means it is the item with
   the highest `P(changes the roadmap)` simply because nothing has been measured against it yet —
   every other item on this list is competing against an existing prior; this one has none.
