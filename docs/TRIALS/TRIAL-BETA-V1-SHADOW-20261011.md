# Beta V1 isolated shadow policy — owner-authorized October 11, 2026

Licence: PRODUCT_EXPERIMENT. Status: DEVELOPMENT / INACTIVE. This successor
implements the owner's newly authorized news/analyst experiment; it changes no
old frozen contract, lane configuration, NAV, activation date or broker authority.

Hypothesis: on authenticated point-in-time component predictions, horizon-specific
shrunk reputation blends may improve the forecast-to-plan decision compared with
the fixed/equal alternatives. Prior: scarce independent date/event blocks and
correlated sources make equal weights hard to improve; losses and abstentions are
expected and must be reported.

Primary prospective metric: paired net excess return versus the same-eligibility
equal blend, under the identical declared entry/exit contract and costs. Retrospective
replay is a direction/mechanics check, never a new forward track record or skill
claim. Binary probability cohorts have separate Brier/log-loss scorecards and
cannot be ranked as if they were expected-return portfolio cohorts.

Frozen candidate set: fixed revision flow; fixed net raises; equal blend; shrunk
adaptive blend; adaptive without news; adaptive without analyst components.
Each comparison uses a common eligible window and instrument set. Unsupported
components remain unavailable/disabled with explicit counts; no invented forecasts,
zero returns on missing prices, fills, news timestamps or analyst horizons.

Development window target: April 11, 2026 through the last completed market session
at sprint acceptance. Actual family-specific coverage governs which windows may be
reported. Use expanding chronological evaluation; only outcomes available before
each vintage cutoff enter its fit. Label windows and related root events are purged;
different tasks, benchmarks and horizons remain separate. Legacy resolution dates
without a time can only supply a disclosed conservative availability upper bound,
never an invented precise timestamp. Protected holdouts/scheduled reads remain shut.

Weight estimator: reuse forecast_reputation shrinkage and expected_return blending.
Freeze the reviewed executable parameters and code hash before first real evaluation;
default shrink k=30, minimum 30 independent horizon/date blocks, gamma=1. Thin
admissible evidence shrinks toward a stated prior. Negative or inadmissible evidence
cannot acquire positive weight merely because all other components are absent.
Calibration/scaling use training labels only. A source extraction is not a return
forecast until its target/unit conversion has independent admissible calibration.

Costs: use the original frozen contract when reproducing it. For newly constructed
equity replay, freeze and report the common per-side cost before measuring, with
an explicit sensitivity table. Never combine costs/horizons across scorecards.

Mandate: inherit the existing personal/PC mandate only after its exact content is
qualified. Preview quantities/allocations remain separate from executed orders.
No strategic SPY holding; SPY is a separate comparator. Keep issuer, cash,
liquidity and correlation constraints explicit. Missing required risk/venue/price
inputs block incremental exposure. Exits/reconciliation remain independent.

Decision rule: this sprint may finish code, measure replay and produce inactive
review drafts; it cannot adopt a live policy from these results. Prospective
inception begins only after reviewed registration/integration and owner activation;
earlier data is discovery/replay and cannot be grandfathered into a forward trial.
Earliest live-adoption decision: NOT SET / OWNER REVIEW REQUIRED. No automatic
adoption threshold, monitoring look or capital authority is created here. The
24-month public skill gate and Monday PC/Bloomberg gates remain unchanged.

Contamination clause: stop the affected cohort on protected-data exposure,
unverified availability, identity conflicts, price-basis mismatch or incompatible
labels. Preserve originals and failed receipts; do not repair history to improve
the result. Explicitly label inaccessible and missing coverage.

What this rule may NOT do: retrain an LLM on historical P&L, change old portfolios,
rewrite probabilities/timestamps/costs/NAV, place broker orders, force a trade,
activate the contest view without authentic Bloomberg membership/rules, or remove
safety gates. This development registration is not a claim that a production
registry row or prospective trial has begun.
