# GRAPH-COVARIANCE-1 — does the semantic graph make a better risk model?

**Pre-registration:** `Aegis module/TRIALS/PREREG_GRAPH_COVARIANCE_1.md`, frozen
at commit `6dcffa8` together with `scripts/gc1_config.py`, **before any
covariance matrix was built or graded**. Registry row `GRAPH-COVARIANCE-1`
written in the same commit.
**Corpse check:** **PASS against 335 prior experiments**; nearest match is its
own parent `PREREG_MARKET_GRAPH_1` at 0.334, which is what a descendant should
look like. `PASS` means *unmatched*, not *novel*.
**Run artifacts:** `Aegis module/runs/GRAPH-COVARIANCE-1/`. `tables.md` is
generated by `scripts/gc1_tables.py`; every number below is printed from it.
**Date:** 2026-08-14. **LLM cost: $0.00** — no vendor call was made. Every arm
is a refit and a matrix solve over the MARKET-GRAPH-1 edge corpus, which was
already paid for.
**Accrues zero arms.** It cannot promote, seed or size anything.

## 0. Verdict

| | pre-registered prior | result |
|---|---|---|
| **H1** — a residual-correlation block predicted **with** the semantic edge features produces a lower-realised-variance minimum-variance portfolio than the identical block predicted without them | ~40/60 against | **NOT DETECTABLE, and pointing the wrong way.** `model_semantic − model_numeric` = **−0.000369** annualised vol (**3.89% worse**) against an MDE of **0.000384** (t = −2.69). Inside its own MDE ⇒ under §19 not a kill and not a win. All three placebos are clean nulls (−0.06%, −0.02%, +0.03%). |
| **H2** — the same improvement survives a long-only, 10%-capped, total-return portfolio | ~15/85 against | **NOT DETECTABLE.** −0.000176 against MDE 0.000324 (t = −1.52). |

**The pre-registered power gate FAILED, and the failure turned out to be the
most valuable thing in the trial.** Chasing why it failed produced a finding
that closes a wider question than the one the trial asked:

> **On this panel, the trailing sample residual correlation matrix is
> statistically indistinguishable from PERFECT FORESIGHT of the realised
> forward correlation matrix, as a minimum-variance risk model.**
> The risk reduction of `oracle_full` over `sample` is **−0.000158** — perfect
> foresight realised marginally *higher* risk — against an MDE of 0.001916,
> **|t| = 0.23**.

Whatever headroom remains for *any* correlation predictor — semantic, numerical
or omniscient — is bounded by that null's own MDE, which is **15.4% of the
entire gain the trailing correlation matrix delivers over knowing nothing**. And
the metric is demonstrably not blind while saying so: the industry-standard
diagonal specific-risk assumption is **86.6% worse** than the sample matrix at
**t = 12.60**.

**What this licenses:** nothing. **What it closes:** the route from
MARKET-GRAPH-1 H1 to portfolio value *through a predicted correlation matrix
fed to a minimum-variance solve*. **What it does not touch:** MARKET-GRAPH-1 H1
itself, which is a statement about pairwise co-movement prediction and is
unaffected by this trial in either direction.

## 1. The instrument broke first, and the first run is disclosed rather than deleted

The first gate run was **VOID**. Its artifacts are committed at
`runs/GRAPH-COVARIANCE-1/void_run_eigfloor_1e-8/` rather than removed.

The number that condemned it is a **pre-declared reported-never-deciding
diagnostic** and it reads no comparison between arms at all:

| | voided run |
|---|---|
| predicted annualised portfolio volatility | **0.00130** |
| realised annualised portfolio volatility | **0.02704** |
| calibration ratio | **4,519** |
| mean condition number after "repair" | **7.1 × 10⁸** |
| mean pre-repair minimum eigenvalue | **−0.126** |

A matrix that forecasts 0.13% annualised volatility for a portfolio that
realises 2.7% is not a risk model. The run was void on that number alone.

**The mechanism, exactly.** The ridge that predicts each correlation entry is
unconstrained and returned values as large as **1.0119**. The assembled matrix
had a minimum eigenvalue of **−0.344**. Flooring eigenvalues at `1e-8` does not
repair such a matrix — it manufactures directions of almost-zero variance, and a
minimum-variance solve is precisely the machine that finds those directions and
levers into them. **Every PSD check passed the entire time**: the repaired
matrices were symmetric, unit-diagonal and positive semi-definite. The repair ran
green and destroyed the object. That is this project's house failure mode wearing
a linear-algebra costume.

**The fix, and why it is not an outcome-driven choice.** Entries are clipped to
[−0.99, 0.99]; the eigenvalue floor is made **relative** to the mean eigenvalue
of a correlation matrix, which is exactly 1 by construction. The value 0.10 was
read off the **spectrum of the predicted matrices** — minimum −0.344, 1st
percentile +0.120, 10th +0.343, median +0.720, maximum 11.3 — so that it removes
the pathological tail and leaves the healthy body of the spectrum alone. It binds
on roughly the bottom 1% of eigenvalues. A spectrum contains no forward return
and no comparison between arms; this is the same class of decision as
MARKET-GRAPH-1's universe amendment, which was likewise decided from composition.

Post-fix, every arm is healthy: calibration 1.22–1.55, gross exposure 1.00–1.25,
condition numbers 24–259, and **no arm is void**.

**Two things now exist that did not.** A runtime `VOID` assertion on the
calibration ratio, so this cannot again depend on a human happening to read a
diagnostic; and a regression test that pins the failure mode under the old floor
and its absence under the new one, so the assertion is about the *fix* rather
than about a constant.

Because the floor remains a judgement call, the primary is additionally reported
at floors {0.05, 0.10, 0.20}. That sensitivity **can only demote**.

## 2. The pre-registered gate was the wrong instrument, and its failure is the finding

`oracle_on_edges` was specified as: write the **true realised forward
correlation** into exactly the edge-carrying entries of the `model_numeric`
matrix, change nothing else. It is the ceiling on any edge-based correction at
0.58% coverage — no real predictor can beat perfect knowledge.

It came in **detectably WORSE**: −0.001598 annualised vol, **16.85% worse** than
`model_numeric`, t = −5.11.

Perfect information, inserted correctly, made the portfolio measurably riskier.
That is not an underpowered gate; it is a broken one, and the reason is
structural rather than statistical. The realised forward correlation has standard
deviation **0.180** across pairs; the ridge's predictions have standard deviation
**0.063**. Writing full-dispersion truth into 0.58% of a matrix whose other
99.42% carries quarter-dispersion predictions produces a matrix **no predictor
could ever emit**, at two incompatible scales. A minimum-variance solve reads the
large inserted entries as hedgeable and takes offsetting positions whose actual
risk is governed by the 99.42% it still has wrong.

Two arms were added to settle it. Both are **declared instrument diagnostics,
neither adoptable**, because both read the outcome:

- **`oracle_full`** — the true forward correlation *everywhere*, so the matrix is
  scale-consistent. It separates "the metric cannot reward a better matrix" from
  "coverage is the binding constraint". Result: **+43.28%, t = +5.22,
  DETECTABLE**. The metric rewards a better matrix decisively.
- **`oracle_feature`** — a *perfect* edge feature fed through the **same
  fixed-alpha ridge** as every real arm, so the resulting matrix is
  scale-consistent by construction. This is the ceiling the pre-registration
  meant to measure: if the semantic block were a perfect predictor of forward
  correlation on the pairs it covers, what could the real architecture buy?
  Result: **−7.57%, t = −3.44, detectably WORSE**.

**The architecture ceiling is negative.** Adding *any* edge-restricted feature to
a globally-fitted entrywise ridge makes the resulting matrix a worse risk model —
even when the feature is perfect. `model_semantic`'s −3.89% is therefore not a
verdict on the graph. It is a verdict on the estimator, and the graph landed
where the ceiling said it would.

## 3. The finding that closes more than this trial

The context arms were pre-registered as reported-never-deciding, and they are
where the trial's real information turned out to live.

| arm | realised resid-GMV vol | vs `model_numeric` | reading |
|---|---:|---:|---|
| `sample` (trailing residual correlation) | 0.00522 | **+44.95%, t = +9.34** | **DETECTABLE** |
| `oracle_full` (perfect foresight) | 0.00538 | +43.28%, t = +5.22 | DETECTABLE |
| `ledoit_wolf` | 0.00637 | +32.86%, t = +6.10 | DETECTABLE |
| `rmt_denoised` | 0.00885 | +6.64%, t = +1.63 | not detectable |
| `model_numeric` (the MG1 baseline ridge) | 0.00948 | — | reference |
| `model_semantic` (the MG1 H1 model) | 0.00985 | −3.89%, t = −2.69 | not detectable |
| `diagonal` (the industry assumption) | 0.01769 | **−86.58%, t = −9.26** | **detectably WORSE** |

Three things follow, in increasing order of importance.

**(a) The MARKET-GRAPH-1 ridge is a much worse risk model than the trailing
correlation matrix it beats on ΔR².** MG1 measured the ridge improving
out-of-sample pairwise correlation MSE (R² 0.126 → 0.127). Here the same ridge
family realises **45% more portfolio risk** than the raw trailing matrix. Both
numbers are correct. **Entrywise squared error and minimum-variance portfolio
risk are different loss functions, and on this panel they point in opposite
directions.** The ridge minimises entrywise error by regressing every entry
toward a common value, which flattens the eigenvalue spectrum — and the spectrum,
not the individual entries, is what a minimum-variance portfolio consumes.
Anything that improves a correlation *model* must be graded on the loss function
it will actually be used under.

**(b) The headroom left for a correlation predictor is bounded, and the bound is
small.** The risk reduction of `oracle_full` over `sample` is **−0.000158
against an MDE of 0.001916, |t| = 0.23 — not detectable**, and the point
estimate is *negative*: perfect foresight of the realised forward correlation
matrix realised marginally **higher** risk than the trailing sample matrix.

Stated as a bound rather than as an absence, because "not detectable" is not
"zero" (§19): the improvement from `diagonal` to `sample` is **+0.012474**, so
this null's own MDE is **15.4% of the entire gain that knowing the trailing
correlation delivers over knowing nothing**. That is the ceiling on what *any*
correlation predictor — semantic, numerical or omniscient — could still add. A
semantic graph covering **0.58%** of pairs is competing for at most that slice,
and only if it were perfect. The pre-committed escalation to more edges is
therefore recommended **cancelled rather than deferred**: it would spend real
compute competing for a gap that has been measured and bounded.

**(c) The metric is not blind, and the positive control proves it.** `diagonal`
— the assumption every commercial risk model actually ships — is **86.58% worse
at t = 12.60 against `sample`**. So the framing this trial was built on is
confirmed in one direction and closed in the other: *specific returns are
emphatically not uncorrelated, and the trailing sample correlation already
captures essentially everything about that which is worth capturing.*

**One honest bound on (b).** All arms share the eigenvalue floor of 0.10, which
caps how much structure any matrix can express. `sample` (T = 252 < n = 300) is
rank-deficient before repair, so the floor is doing substantial regularisation
work for it — `sample` here means "the trailing matrix with its noise
eigenvalues lifted", which is itself a denoising estimator. The floor sensitivity
in §5 is what tests whether relaxing that cap reopens any headroom.

## 4. Which controls ran, and what they cannot cover

**All pre-registered controls ran. None was skipped.**

| control | ran? | outcome |
|---|---|---|
| `placebo_shuffled` (node-label permutation, degree + confidence preserved) | **yes** | −0.06%, MDE 0.0009%-scale — **null** |
| `random_matched_density` | **yes** | −0.02% — **null** |
| `placebo_stratified` (permuted within date × sector × ρ_trail decile) | **yes** | +0.03% — **null** |
| `model_numeric` baseline (the thing to beat) | **yes** | the reference in every delta |
| the power gate | **yes** | **failed, and the failure is §2** |
| H2 long-only capped total-return portfolio | **yes** | not detectable |

The placebos are unusually clean here — all three sit within 0.06% of the
reference, against a real-arm effect of −3.89%. Whatever `model_semantic` did, it
is attached to the real edges and not to the nuisance channel the
pre-registration named in advance (the standardised block shifting every
non-edge pair by a constant).

**Controls that did NOT run, and are therefore not passed:**

- **No per-edge-type decomposition.** `competitor` is 51% of the graph. Which
  edge types carry what was not measured, here or in the parent.
- **No re-grade on quote-verified edges only.** 10.8% of the parent's evidence
  quotes did not verify verbatim; restricting to the 89.2% that did is the
  obvious hallucination sensitivity and it was not run.
- **No alternative portfolio objective.** Minimum variance is the pre-registered
  loss function because it contains no return forecast. A risk-parity,
  maximum-diversification or tracking-error objective might rank the arms
  differently, and that is unmeasured rather than ruled out.
- **No second universe size.** Every number is at `UNIVERSE_N = 300`, one
  horizon (126 days), one panel (2015–2024).

**What the design cannot rule out, however many controls pass:**

- The conclusion in §3(b) is a statement about **this metric at this universe
  size and horizon**. It says the correlation *matrix* has no headroom for a
  minimum-variance portfolio of 300 large-cap US names. It does not say the
  semantic graph is uninformative about co-movement — the parent measured that it
  is — nor that no portfolio objective can use it.
- Everything inherits the parent's biased subgraph: 69% of extracted
  relationships never reach the panel because the counterparty is foreign,
  private or a subsidiary, and 48.3% of documents produce no edge at all.
- Nothing here has been costed, traded, or passed through G7. These are realised
  variances, not returns. Descriptive only, as pre-registered.

## 5. The eigenvalue-floor sensitivity — and the caveat it resolves

The rule was frozen in advance: this sensitivity **can only demote**.

| floor | H1: semantic − numeric | MDE | t | reading | headroom: `oracle_full` over `sample` | its MDE | reading |
|---|---:|---:|---:|---|---:|---:|---|
| 0.05 | −0.000277 | 0.000572 | −1.36 | not detectable | −0.000377 | 0.001954 | not detectable |
| **0.10** *(frozen)* | −0.000369 | 0.000384 | −2.69 | not detectable | −0.000158 | 0.001916 | not detectable |
| 0.20 | −0.000281 | 0.000277 | −2.84 | **detectably WORSE** | +0.000230 | 0.001828 | not detectable |

**Two readings, and they demote in the honest direction.**

**H1 is sign-stable and never points the right way.** At all three floors the
semantic block raises realised risk. Its *detectability* moves: not detectable at
0.05 and 0.10, detectably worse at 0.20. So the verdict at the frozen floor
stands as `NOT_DETECTABLE`, and it is recorded as **fragile in the harmful
direction** — a tighter numerical floor turns the null into a detectable
degradation. Under §19 that is still not a kill for the graph; it is a kill for
this way of using it.

**The headroom result survives its own caveat, which is the important part.**
§3(b)'s bound is only honest if the eigenvalue floor is not itself what is
hiding the gap — the floor caps how much structure *any* matrix can express,
including the oracle's. It is not: `oracle_full` vs `sample` is **not detectable
at every floor tested** (|t| = 0.54, 0.23, 0.35), and the point estimate changes
sign across floors, which is what a genuine zero looks like. Relaxing the cap by
a factor of four does not reopen a gap for a correlation predictor to compete
for.

## 6. Consequences

1. **Do not build GRAPH-SHRINK-1 or any further "improve the covariance matrix"
   descendant at this universe size.** The measurement in §3(b) says the gap
   such a trial would compete for does not exist. This is the cheapest possible
   death for a family that looked like the shortest path to product value, and
   it cost $0 in vendor spend.
2. **MARKET-GRAPH-1 H1 stands, unweakened and un-strengthened.** This trial did
   not test it. What is now known is that its route to portfolio value does not
   run through a predicted correlation matrix fed to a minimum-variance solve.
3. **A reusable instrument rule, earned here:** *a model improvement measured
   under one loss function may not be assumed under another, and on this panel
   entrywise correlation MSE and portfolio risk disagree by 45% in opposite
   directions.* Any future arm claiming a "better" covariance, correlation or
   risk estimate must print the loss function it will be used under.
4. **A second reusable rule:** *a sparse correction inserted into a dense
   estimate at a different dispersion scale is not a ceiling — it is a different
   and worse estimator.* An oracle must be constructed inside the architecture it
   is the ceiling for. `oracle_on_edges` was not; `oracle_feature` was.
5. **The remaining Track B descendants are unaffected** — `REACTION-GAP-1`,
   `SEMANTIC-SYSTEMIC-RISK-1`, `MARKET-GRAPH-2` and
   `SEMANTIC-NUMERIC-DIVERGENCE-1` all live on residual *returns* and *events*,
   not on the covariance matrix, so none of them competes for the gap this trial
   measured to be empty.
