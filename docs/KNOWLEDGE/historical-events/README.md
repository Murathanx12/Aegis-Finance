# Historical event lessons

These are dated, retrospective lessons for the shared knowledge universe. They do not record prior predictions, backtests, live Brain state, trades, or owner delivery.

Append a new `HIST-<UTC entry date>-<first 12 characters of body SHA-256>.md` note for each lesson. Hash the UTF-8 body after the second frontmatter delimiter with LF line endings. Keep event, publication, observation, and entry clocks distinct; cite sources and counterevidence. Do not edit an accepted note in place. Put corrections in a new note with `supersedes_id` pointing to the earlier ID.

Discover notes with `rg -n "HIST-" docs/KNOWLEDGE/historical-events`. Knowledge ingestion, if authorized later, is a separate step.
