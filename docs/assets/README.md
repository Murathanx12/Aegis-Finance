# docs/assets: the public asset registry

Every file in this folder is produced by the command in its row; none is hand-edited (the README's
repo map says the same of this folder). **Licence of every file here: MIT**, the repository
[`LICENSE`](../../LICENSE) (Copyright (c) 2026 Murathanx12).

Nothing in this folder is a performance claim. The identity assets print
`RESULT IMPROVEMENT: NONE`; the figures carry their own evidence label and receipt in the README
section that shows them.

**What keeps them honest.** [`backend/tests/test_public_assets.py`](../../backend/tests/test_public_assets.py)
fails when a committed SVG differs from a fresh render, when a module path printed in the diagram
stops existing or a function printed beside it (`u_plan`, `AegisSimOwner`, ...) stops being
defined, when the quoted sentence or the dated acceptance tally leaves the V1 Beta doc, when an SVG
could load anything external, or when the README shows an asset that is not here. Without pytest:
`python -m scripts.render_public_assets --check` (exit 1 when an SVG is stale; writes nothing).

**Changing the diagram.** Edit `STAGES` (or the footer constants) in the generator, re-render, and
commit the generator and both SVGs together. A new V1 doc means a new `SOURCE_DOC`, `STATE_DATE` and
`V1_TALLY`; the test reads the tally out of the cited doc, so a stale one is a red test, not a
stale picture. Strings are kept inside fixed character budgets (`MAX_*_CHARS`) measured for the
widest common fallback fonts (DejaVu Sans / Sans Mono), because SVG text does not wrap.

### Exporting the PNG

The command used on 2026-10-07, on the cloud box where Chromium is already installed for
Playwright (no package installed, nothing added to the repo):

```bash
CHROME=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell
"$CHROME" --no-sandbox --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1200,630 --screenshot="$PWD/docs/assets/og_preview.png" \
  "file://$PWD/docs/assets/og_preview.svg"
python -c "import struct; b=open('docs/assets/og_preview.png','rb').read(); print(struct.unpack('>II', b[16:24]))"
# -> (1200, 630)
```

Any Chrome or Chromium does the same (`chrome --headless --hide-scrollbars --window-size=1200,630
--screenshot=<abs path> file:///<abs path to og_preview.svg>`); `--no-sandbox` is there only because
the cloud box runs as root. The test checks the PNG's size from its IHDR header when the file exists.

**Setting it as the repository's social preview is the owner's step:** GitHub → the repository →
Settings → General → Social preview → Edit → Upload an image → `docs/assets/og_preview.png`.
