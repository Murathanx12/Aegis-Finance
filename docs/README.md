## Reading rules

Three conventions make this record trustworthy, and they're worth knowing
before you read:

1. **Every effect is printed beside its own 80%-power MDE.** A number inside
   its MDE is *not detectable* — neither a kill nor a win (CANON §19).
2. **A check that did not run is not a check that passed.** Documents state
   which controls did *not* run.
3. **Verdicts are frozen.** A superseded document gets a banner, never an
   edit that changes what it claimed at the time.
